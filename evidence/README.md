# Evidence Policy

Raw recordings and heavy outputs remain outside Git.

This directory may contain only checksums, manifests, bounded fixtures, logs, plots, and concise summaries needed to support a reviewable claim. Bounded fixtures must be minimal, non-sensitive, and justified by a falsifying test.

Real data will be attached later from the home WSL analysis machine through external references and checksummed manifests. No raw-data setup on the current work computer is required for this bootstrap.

Do not place secrets, user-specific absolute paths, or unbounded generated output here.
